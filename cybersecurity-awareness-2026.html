01 Threat Landscape

6 ภัยที่มุ่งโจมตีธุรกิจประกันและการเงิน

ถือข้อมูลลูกค้า ประวัติสุขภาพ และธุรกรรมการเงินจำนวนมาก จึงเป็นเป้าหมายอันดับต้นๆ

Phishing

อีเมล/เว็บปลอม หลอกเอารหัสผ่านและข้อมูลลูกค้า

36%ของการโจมตีเริ่มจาก Phishing

Ransomware

เข้ารหัสไฟล์แล้วเรียกค่าไถ่ ทำให้งานบริการลูกค้าหยุดชะงัก

2×ขู่ซ้ำ: เข้ารหัส + ขู่ปล่อยข้อมูล

BEC

แอบอ้างผู้บริหารหรือคู่ค้า สั่งโอนเงิน/เปลี่ยนเลขบัญชี

$2.77Bความเสียหาย (FBI IC3 2024)

Data Breach

ข้อมูลลูกค้ารั่วไหล ทั้งจากการโจมตีและความผิดพลาดของคน

$4.88Mค่าเสียหายเฉลี่ยต่อครั้ง (IBM 2024)

Quishing

QR Code ปลอมพาไปเว็บหลอกหรือโหลดมัลแวร์

1.7M+QR Code อันตราย

Deepfake / Vishing

AI ปลอมเสียงหรือวิดีโอ แอบอ้างเป็นผู้บริหารหรือลูกค้า

$25Mถูกหลอกโอนผ่านวิดีโอคอลปลอม

02 Cyber Hygiene

รหัสผ่าน: ควรทำ กับ ไม่ควรทำ

✓สิ่งที่ควรทำ

  • ยาว 12 ตัวขึ้นไป หรือใช้ Passphrase
  • ใช้รหัสผ่านต่างกันทุกบัญชี
  • ใช้ Password Manager ช่วยสร้างและจำรหัส
  • เปิด MFA ทุกบัญชีที่รองรับ
  • เปลี่ยนทันทีเมื่อสงสัยว่ารั่วไหล

✕สิ่งที่ไม่ควรทำ

  • ใช้ข้อมูลส่วนตัว เช่น วันเกิด ชื่อ
  • ใช้รหัสผ่านซ้ำหลายบัญชี
  • จด Sticky Note ติดหน้าจอ
  • แชร์รหัสผ่านกับผู้อื่น
  • ส่งรหัสผ่านทางอีเมลหรือแชท

นิสัยพื้นฐานที่ต้องทำทุกวัน

อุปกรณ์ & โต๊ะทำงาน

  • อัปเดตระบบและแอปติดตั้ง Update เมื่อมีแจ้งเตือน อย่าเลื่อนนาน
  • ล็อกหน้าจอทุกครั้งที่ลุกWin + L · Ctrl + Cmd + Q
  • Clean Deskไม่ทิ้งเอกสารลูกค้าหรือรหัสผ่านไว้บนโต๊ะ

Wi-Fi สาธารณะ

  • เลี่ยงธุรกรรมสำคัญไม่เข้าระบบงาน ไม่กรอกรหัสผ่าน
  • ใช้ VPN ของบริษัทเข้ารหัสการเชื่อมต่อทุกครั้ง
  • ปิด Auto-connectระวัง Wi-Fi ชื่อเหมือนร้านจริง

สำรองข้อมูล (Backup)

  • กฎ 3-2-13 สำเนา · 2 สื่อ · 1 ชุดเก็บแยก
  • เก็บไฟล์ในที่ที่บริษัทกำหนดไดรฟ์กลาง / Cloud ที่ได้รับอนุมัติ
  • ทดสอบกู้คืนBackup ที่กู้ไม่ได้ เท่ากับไม่มี

02 Cyber Hygiene

จัดการข้อมูลลูกค้าตามชั้นความลับ

  1. 01

    ลับมาก · Restricted

    ข้อมูลสุขภาพ ประวัติเคลม เลขบัตรประชาชน — เข้ารหัส เข้าถึงเฉพาะผู้มีสิทธิ์

  2. 02

    ลับ · Confidential

    ข้อมูลกรมธรรม์ เบอร์โทร ที่อยู่ลูกค้า — ห้ามส่งออกนอกระบบบริษัท

  3. 03

    ใช้ภายใน · Internal

    ระเบียบ คู่มือ เอกสารประชุม — แชร์ได้เฉพาะพนักงาน

  4. 04

    เปิดเผยได้ · Public

    โบรชัวร์ ข่าวประชาสัมพันธ์ — เผยแพร่ได้หลังได้รับอนุมัติ

* ระดับชั้นความลับและวิธีจัดการ ให้ยึดตามนโยบายของบริษัทเป็นหลัก

ภัยยุค AI: เนียนจนแยกไม่ออก

Deepfake เสียงVoice Clone

03 AI Threats

Shadow AI: ใช้ AI อย่างปลอดภัย

ความเสี่ยงจากการนำข้อมูลลูกค้าหรือเอกสารภายใน ไปใช้กับเครื่องมือ AI ที่องค์กรไม่ได้อนุญาต

✓ใช้ได้

  • ใช้เครื่องมือ AI ที่องค์กรอนุมัติเท่านั้น
  • ตัดชื่อ เลขบัตร ข้อมูลลูกค้าออกก่อนใช้
  • ตรวจคำตอบของ AI ก่อนนำไปใช้จริง
  • ไม่แน่ใจ ถามฝ่าย IT / Security

✕ห้ามทำ

  • วางข้อมูลลูกค้าในแชตบอทสาธารณะ
  • อัปโหลดสัญญาหรือเอกสารภายใน
  • ติดตั้งส่วนขยาย AI ที่ไม่ได้รับอนุญาต
  • ให้ AI เข้าถึงอีเมลหรือไดรฟ์บริษัทเอง

04 Apps & Accounts

ใช้แอปและบัญชีอย่างปลอดภัย

  1. 01

    แยกบัญชีงาน–ส่วนตัว

    ไม่ใช้อีเมลบริษัทสมัครบริการส่วนตัว ไม่ส่งไฟล์งานเข้าบัญชีส่วนตัว

  2. 02

    ตรวจ Permission ของแอป

    แอปไฟฉายไม่จำเป็นต้องขอรายชื่อ ข้อความ หรือสิทธิ์ Accessibility

  3. 03

    ตั้งค่าความเป็นส่วนตัว

    Social Media / LINE: ปิดการค้นหาด้วย ID หรือเบอร์ ซ่อนข้อมูลส่วนตัว

  4. 04

    แชร์ไฟล์บน Cloud

    แชร์เฉพาะบุคคล เลี่ยง “Anyone with the link” และตั้งวันหมดอายุ

  5. 05

    Log out & ตรวจประวัติ

    ออกจากระบบบนเครื่องอื่นทุกครั้ง ตรวจรายการอุปกรณ์ที่ล็อกอินอยู่เป็นประจำ

05 Download & MFA

ตรวจสอบก่อนดาวน์โหลดหรือติดตั้ง

แหล่งที่เชื่อถือได้

  • App Store / Google Play / เว็บทางการพิมพ์ URL เอง ไม่คลิกจากโฆษณา
  • ไม่ติดตั้งไฟล์จากแชตเช่น ไฟล์ .apk ที่ส่งมาทาง LINE / SMS
  • เครื่องบริษัท ขอ IT ก่อนติดตั้งเฉพาะโปรแกรมที่ได้รับอนุมัติ

สังเกตแอปปลอม

07 Case Studies

กรณีศึกษา: พลาดครั้งเดียว กระทบทั้งองค์กร

Case 01 · สถานการณ์ตัวอย่าง

คลิกลิงก์ Phishing

พนักงานกรอกรหัสผ่านในหน้า Login ปลอม คนร้ายใช้อีเมลนั้นส่ง Phishing ต่อให้ลูกค้าและเพื่อนร่วมงาน

บทเรียนตรวจ URL ก่อนกรอกรหัสผ่าน และเปิด MFA ทุกบัญชี
Case 02 · สถานการณ์ตัวอย่าง

ติด Ransomware

เปิดไฟล์แนบที่ดูเหมือนใบแจ้งหนี้ มัลแวร์เข้ารหัสไฟล์ในเครื่องและไดรฟ์ที่แชร์ร่วมกัน งานหยุดหลายวัน

บทเรียนอย่าเปิดไฟล์แนบที่ไม่คาดหวัง และมี Backup ที่กู้คืนได้จริง
Case 03 · เหตุการณ์จริง 2024

วิดีโอคอลปลอมเป็นผู้บริหาร

พนักงานบริษัทวิศวกรรมสาขาฮ่องกง โอนเงินราว US$25M หลังประชุมวิดีโอกับ “CFO” และทีมงานที่สร้างด้วย Deepfake ทั้งหมด

บทเรียนคำสั่งโอนเงินผิดปกติ ต้องยืนยันผ่านช่องทางอื่นเสมอ
